What Footon is

Overview

A free-to-play mobile web app. Friends predict football moments together during live matches (“Next corner before 75'?”), set pre-match predictions with a coin stake, and compete in small private leagues called challenges, each on one match.

Three things that never mix

MeansEarned bySpent onShown as
PointsSkillRight calls only (+50)NothingRank, leaderboards, prizes
CoinsPlay moneyMissions, pool wins, right predictions, free table top 3Entries, stakes, chat questions, creating a league, later the shopWallet, stakes, payouts
PrizesReal items from sponsorsWeekly or monthly rank (points)—Wallet strip

Coins can never be cashed out or sent to another user. Nothing that earns points is for sale. Every field in this doc maps to something a screen shows today; the source shapes are src/lib/mock-data.ts, economy.ts and predictions.ts.

How every call behaves

Conventions

TopicRule
TransportREST + JSON over HTTPS, base path /v1. One WebSocket for pushes (SSE also fine).
AuthAuthorization: Bearer <token> on everything except /v1/auth/*.
IDsOpaque strings. The app never parses them.
TimesISO 8601 in UTC. The app formats “21:00”, “Tomorrow”, “Thu 5 Nov” itself. Never send display labels.
Coins, points, XPIntegers. No decimals. Negative = a spend.
PercentagesIntegers 0–100. Splits sum to 100; round on the server.
Match minuteminute + optional addedTime (45+2').
Missing dataOmit the field or send null. Never invent stats: the app hides a tab when its data is missing.
Pagination?limit=20&cursor=… → { items, nextCursor }.
IdempotencyEvery call that moves coins takes an Idempotency-Key header. A retry returns the first result and never charges twice.
Coin writesReturn the new wallet with the payload, so the island updates without a refetch.
Errors{ error: { code, message, details } }. The app writes its own copy from code + details.

Predictions

Markets

typeLabelMin stakeOptions (value)
resultWin / draw1001 (home) · X (draw) · 2 (away)
goalsGoals100Under 2.5 · Over 2.5 · Over 3.5
cornersCorners100Under 9.5 · Over 9.5 · Over 11.5
yellowsYellow cards100Under 3.5 · Over 3.5 · Over 5.5
redRed card200Yes · No
penaltyPenalty200Yes · No

PUT rules, in order

  1. Reject after kickoffAt.
  2. One item per type; pick must be a listed option.
  3. Stake at least the minimum, or exactly the challenge's fixed stake.
  4. Total within the challenge cap.
  5. Charge (or refund) the difference from the old total. Short → 402 with short.
  6. Write one CoinEntry per change.

Hard rules

  • Points, coins and prizes never mix. Rank and prizes read points only. An entry or stake never changes rank.
  • Coins can't be cashed out or sent to another user.
  • Nothing that earns points is for sale. No mystery boxes.
  • No pressure selling: no purchase prompts after a loss or on a low balance, no fake timers, no “sold out”.
  • Coin packs are 18+ with a monthly limit (when payments ship).
  • The ledger is append-only. Balance = sum of CoinEntry rows and never goes below zero.
  • The server is the authority. Never trust a total or payout the app computed.
